# AI Takeover Framework for Authoritative Multiplayer Game Servers

## Overview

This thesis presents the design, implementation, and evaluation of an **AI Takeover framework** for preserving gameplay continuity in real-time multiplayer games experiencing severe network degradation.

Authoritative multiplayer games rely on a continuous stream of player inputs reaching the server. When network conditions deteriorate due to latency, jitter, packet loss, or temporary input interruptions, the server may stop receiving reliable commands from a player, resulting in freezes, unstable movement, and a degraded gameplay experience.

The proposed framework addresses this problem by dynamically replacing missing or unreliable player inputs with commands generated by a locally executed AI policy. Rather than improving player performance, the objective is to maintain gameplay continuity while minimizing disruption to both the affected player and the rest of the session.

## Framework Implementation

The framework is implemented in **Unity** using **Netcode for GameObjects** and **Unity ML-Agents**, and includes:

* Configurable simulation of adverse network conditions
* Telemetry logging for gameplay and networking events
* Blind experimental scenarios
* Post-session subjective questionnaires for Quality of Experience evaluation

## Experimental Prototypes

The framework is validated through two progressively more complex multiplayer environments.

### Kart Racing

The first prototype evaluates AI takeover in a structured racing environment with procedurally generated tracks. Reinforcement Learning using **Proximal Policy Optimization (PPO)** and reward shaping is employed to train policies capable of:

* Following racing trajectories
* Completing laps
* Maintaining stable vehicle control
* Avoiding collisions

### Kart Football

The second prototype extends the evaluation to a dynamic, team-based environment involving cooperative and competitive interactions between multiple agents.

Policies are trained using a staged learning pipeline consisting of:

* Behavioral Cloning for policy initialization
* Proximal Policy Optimization (PPO)
* Curriculum learning
* Team-based reinforcement learning

This prototype introduces significantly richer gameplay dynamics, requiring interaction with teammates, opponents, and the game object while adapting to continuously changing situations.

## Evaluation

The framework is evaluated using both objective and subjective methodologies, including:

* Gameplay performance metrics
* Network exposure measurements
* Quality of Experience (QoE) questionnaires
* Lateral disruption analysis to quantify the impact of AI takeover on nearby players

These evaluations assess not only the ability of the framework to preserve the affected player's experience during network degradation, but also its influence on the overall multiplayer session.

## Scope

Although the experiments focus on the Kart Racing and Kart Football prototypes, the proposed architecture is designed to be applicable to a wider range of real-time multiplayer games and authoritative networking architectures where temporary loss of player input may occur.
